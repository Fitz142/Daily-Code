DAILY CODE NEWS - PETUNJUK

Isi folder:
- index.html : struktur halaman
- style.css  : warna, ukuran, layout, dan desain responsif
- script.js  : filter berita, pencarian, menu HP, mode gelap, serta form demo
- Bagian Watch & Learn di index.html : video YouTube tertanam untuk belajar HTML/CSS

Cara menjalankan:
1. Ekstrak file ZIP ke folder yang mudah ditemukan.
2. Pastikan ketiga file tetap berada dalam folder yang sama.
3. Klik dua kali index.html untuk membukanya di browser.
4. Koneksi internet diperlukan untuk Google Fonts dan gambar dari Unsplash.

Catatan:
- Artikel di halaman ini adalah konten contoh, bukan berita live.
- Form newsletter hanya demo dan belum mengirim email.
- Situs ini dibuat menggunakan HTML, CSS, dan JavaScript biasa tanpa framework.
